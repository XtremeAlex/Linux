# Linux

Guide passo passo per installare e configurare distribuzioni Linux, scritte per
chi sta muovendo i primi passi con i server. Ogni schermata è commentata, così
si può seguire anche senza esperienza.

> Stato: materiale storico (2021). La guida è scritta per Ubuntu Server 20.04.

## Guide

- [Ubuntu Server](ubuntu/): installazione illustrata di Ubuntu Server 20.04,
  usata anche come base per il cluster della guida
  [Kubernetes](https://github.com/XtremeAlex/Kubernetes)
